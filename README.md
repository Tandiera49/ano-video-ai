# ANO VIDEO AI

Open-source Image-to-Video generator.

## Features

- Image to Video
- Reference image
- Motion prompt
- Seed control
- Frame control
- MP4 output
- TikTok / Reels / Shorts workflow

## Model

Wan-AI/Wan2.1-I2V-14B-480P-Diffusers

## Hardware

Designed for Hugging Face ZeroGPU.
